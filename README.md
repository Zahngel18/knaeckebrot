# 🍞 Knäckebrot (Shithead)

Online-Kartenspiel für 2–5 Spieler – jeder auf dem eigenen Handy, verbunden über einen Spiel-Code.

**Spielen:** https://zahngel18.github.io/knaeckebrot/

- Einer tippt „Neues Spiel starten" und teilt den 5-stelligen Code
- Die anderen geben den Code ein und treten bei
- Tutorial über den ❓-Button, Joker-Option in der Lobby
